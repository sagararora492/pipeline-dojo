# Research notes

Shared notes behind each lesson, in `research/<track>/<topic>.md`.

Each notes file should include:

- **Sources:** links to primary sources (official docs, books, original papers),
  with the version or date checked.
- **Key claims:** each one tied to a source.
- **Open questions:** anything still marked `[VERIFY]`.
- **Dialect or version differences** worth calling out in the lesson.

Lessons in `content/` are written from these notes; see "Writing content
together" in [CLAUDE.md](../CLAUDE.md).
